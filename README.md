# Word 格式化小助手

> 一款轻量级文档处理插件，专注于解决文档写作中最耗时、最琐碎的数据清理与排版规范问题。它帮助用户在几秒钟内完成原本需要手动逐行调整的工作，让文档格式整洁统一、内容清晰可读。

Word 格式化小助手支持 Word 文档（`.doc` / `.docx`）的**格式清洗**、**模板格式化**和**标题自动编号**，全程在本地浏览器内完成，不上传任何文件，安全可靠。

---

## ✨ 功能特性

### 🧹 格式清洗（13 项）
| 类别 | 功能 | 说明 |
|------|------|------|
| **字符清理** | 删除零宽字符 | 清除不可见字符，避免内容错乱 |
| | 删除软连字符 | 清理自动换行产生的隐形连字符 |
| | 删除不可见控制字符 | 清除控制类特殊字符 |
| | 不间断空格→普通空格 | 规范空格类型 |
| | 制表符→空格 | 统一对齐符号 |
| | 合并多余空格 | 连续空格合并为一个 |
| **排版清理** | 删除行首空格 | 消除段落前多余缩进 |
| | 删除行尾空格 | 清理行尾残留空格 |
| **格式清理** | 清除超链接格式 | 转为纯文本，去掉链接样式 |
| | 清除手动颜色 | 恢复为自动颜色 |
| | 清除手动高亮 | 移除背景高亮 |
| | 清除隐藏文字 | 删除或显示隐藏文字 |
| | 删除空编号行 | 删除只有编号、无内容的段落 |

### 🎨 模板格式化
提供两套格式化模板：

**专用模板**：A4 纸张，标准页边距，宋体 + Times New Roman，1.5 倍行距，四级标题（一、/（一）/1./（1））各自指定字号对齐与段距，正文小四宋体首行缩进两端对齐。

**通用模板**：A4 纸张，微软雅黑，标题 18/16/15/14pt 加粗，1.2 倍行距。

### 📑 标题自动编号
- 自动删除旧编号
- 四级标题自动编号（一、/（一）/1./（1））
- **父子依赖联动**：一级标题变化后，下级标题编号自动重排
- 正文列举项可统一转为实心圆点 ●

### 📊 表格设置
- 边框粗细、表头背景、单元格对齐、表头加粗、整体对齐、列宽调整均可独立配置
- 黑色实线边框、行高最小值固定

### 📋 运行日志
实时展示每一步处理过程，方便查看与核对。

## 📥 安装使用

### 作为 uTools 插件
1. 下载/构建插件包（见下方"开发构建"）
2. 在 uTools 中输入 **`wd`** 即可打开 Word 格式化小助手

### 作为 Web 应用
1. 克隆本项目
2. 安装依赖：`npm install`
3. 启动开发：`npm run dev`
4. 浏览器打开生成的地址即可使用

---

## 🚀 使用步骤

### 第一步：上传文档
点击选择或拖拽 Word 文档（支持 `.doc` / `.docx`），系统自动预检测标题层级结构。

### 第二步：格式清洗
- 选择需要清理的项目（支持**一键预设**：全面清洗 / 仅字符清理 / 排版清理 / 不清洗）
- 配置隐藏文字处理方式

### 第三步：模板格式化
- 选择模板（专用 / 通用）
- 配置表格设置、标题编号、正文列举项转圆点等

### 第四步：开始处理
点击"开始处理"，系统完成清洗、编号、格式化，并展示处理结果。

### 第五步：导出
- **导出 Word 文档**：下载格式化后的 `.docx`
- **导出质检报告**：下载处理数据的 `.txt` 报告

## 🔧 开发构建

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 生产构建（生成到 dist/）
npm run build

# 运行自动化测试
npm test
```

### 技术栈
- **Vue 3** + **Vite 6**
- **JSZip**：docx 读取与写回
- **word-extractor**：解析旧版 .doc 文件
- **@xmldom/xmldom**：XML 处理（开发测试）
- 纯浏览器端处理，文件不上传服务器
